# Thalayattam Nod AI

Build a complete, polished, responsive web application called:

THALAYATTAM TECHNOLOGIES

IMPORTANT:

This is a college AI project, but the website should NOT look like a typical college project or generic AI dashboard.

The visual identity is extremely important.

Create an original nostalgic early-2000s internet / webcore / scrapbook website with a playful Malayali personality.

The design should feel like:

A cute personal website from the early 2000s

+

a handmade scrapbook

+

an old computer/webcam interface

+

modern interactive web technology

+

Malayali humor

+

AI computer vision.

The website should feel intentionally handmade, quirky, slightly chaotic and imperfect, while still being polished, readable and functional.

DO NOT use a generic SaaS design.

DO NOT use a standard corporate landing page.

DO NOT use a futuristic cyberpunk AI design.

DO NOT use a plain white minimalist layout.

DO NOT make it look like a Kerala tourism website.

==================================================

PROJECT CONCEPT

==================================================

Project name:

THALAYATTAM TECHNOLOGIES

Tagline:

"Because apparently, even a nod needs technology."

Concept:

Thalayattam Technologies is a fun AI-powered computer vision application that interprets different culturally familiar Malayali head movements.

The application recognizes five responses:

ATHE — Yes

SHERI — Okay

VENDA — No

NOKKAM — Let's see

ARIYILLA — Don't know

Main hero heading:

"WHAT DID YOUR NOD SAY?"

Hero subtitle:

"An AI that understands the unspoken language of the Malayali nod."

MOCK AI

==================================================

The real Python AI backend is being developed separately.

Therefore implement a complete MOCK MODE.

The UI must work even without a backend.

When the user clicks:

START DETECTION

simulate:

WAITING

→ DETECTING

→ ANALYZING

→ RESULT

Use realistic short delays.

Return one of the five gestures.

Use realistic confidence values between approximately 0.80 and 0.98.

Create:

predictGesture()

inside a separate API/service layer.

Do NOT put mock prediction logic directly inside the visual components.

The mock function should return:

{

  "gesture": "Athe",

  "confidence": 0.94,

  "message": "Athe, manassilaayi."

}

Create:
